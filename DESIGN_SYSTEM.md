# Design System

## Product
B2B Inventory Management SaaS

## Design Direction
- Desktop-first
- Professional enterprise SaaS
- Clean
- High information density
- Low visual noise

## Layout
- Sidebar: 240px
- Header: 64px
- Page padding: 24px
- Content max width: 1440px

## Components
### Data Table
- Row height: 44px
- Compact density
- Numeric values right aligned
- Sticky header

### Buttons
- Border radius: 6px
- Primary action: solid
- Secondary action: outline


## Typography

### Font Family

- Korean: Noto Sans KR
- Latin / English / Numbers: Inter
- Fallback: system-ui, sans-serif

### Font Usage

- Korean text → Noto Sans KR
- English text → Inter
- Numbers → Inter
- Alphanumeric product codes → Inter
- Mixed Korean/English text → Noto Sans KR + Inter fallback

### CSS Font Stack

font-family:
  "Inter",
  "Noto Sans KR",
  system-ui,
  sans-serif;
